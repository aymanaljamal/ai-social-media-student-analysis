# Security Policy

## Supported Versions

This project is currently an educational Data Science project.

Security fixes will generally be applied to the latest development version.

| Version        | Supported |
| -------------- | --------- |
| Latest         | Yes       |
| Older versions | No        |

---

## Reporting a Security Issue

If you discover a security vulnerability, please do not publicly disclose sensitive details in a GitHub Issue.

Instead, contact the project maintainer privately with:

* A description of the vulnerability.
* Steps to reproduce it.
* Potential impact.
* Any suggested mitigation.

---

## Sensitive Information

Do not commit sensitive information to the repository, including:

* Passwords.
* API keys.
* Access tokens.
* Private credentials.
* Personal user information.
* Private configuration files.

Use environment variables or local configuration files for sensitive values.

---

## Dataset Privacy

The project uses a publicly available dataset for educational and analytical purposes.

The repository should not contain additional private or personally identifiable information collected outside the public dataset.
